这个网关做什么
自动发现、统一目录、兼容接入

        
    
          
  • 自动发现：巡检免 Key provider 的 /models，把在线免费模型加入可用池。
    • 
          
  • 统一目录：合并两套 provider 目录，按模态、上下文、Key 要求和在线状态分类。
    • 
          
  • 健康巡检：记录在线 / 降级 / 离线 / 需要 Key，失败后自动冷却并换路由。
    • 
          
  • OpenAI 兼容：提供 /v1/models、/v1/chat/completions、流式输出和 model: auto。
    • 
          
  • 自动路由：免 Key 优先，再按延迟和近期使用量挑选；失败自动尝试下一条。
    • 
          
  • 本地 Key：需要 Key 的 provider 可在看板填写，只写入本机 data/keys.json。
    • 
          
  • 零本地模型：不下载权重，所有推理都走第三方免费 API。
    • 
          
  • 元数据日志：只记录时间、模型、状态、延迟和 token，方便排查限流。
    • 
        

        
免费层可能限流、记录或审查请求。不要向免 Key provider 发送机密代码、客户数据或个人信息。
